# Base Dashboard Listing Draft

- **Application name:** Base Portfolio Reader
- **Short description:** Read-only Base mainnet portfolio analytics for ETH and selected ERC-20 balances, powered by a dependency-free JavaScript calculation toolkit.
- **Website:** `https://huklaa.github.io/crypto-test/` (available after GitHub Pages deployment succeeds)
- **GitHub repository:** https://github.com/huklaa/crypto-test
- **Category:** Analytics / Portfolio
- **Base usage:** Reads public Base mainnet balances through Ethereum JSON-RPC, validates chain ID 8453, links accounts to the Base block explorer, and performs portfolio calculations locally. It does not connect wallets, sign messages, or submit transactions.

The repository owner must review the final listing and submit it from their Base.dev account. No application registration is performed by the demo itself.
