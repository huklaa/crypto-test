# Changelog

All notable changes to this project are documented here. This project follows [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-08-09

### Added

- Dependency-free market analytics and formatting utilities.
- Portfolio valuation, allocation, DCA, profit/loss, drawdown, and rebalancing tools.
- Trading fee, slippage, position sizing, stop-loss, take-profit, and risk/reward helpers.
- Staking reward, compounding, annualized return, and fee-adjusted yield calculations.
- Input validation, token symbol normalization, Node.js tests, and GitHub Actions CI.
- Base ecosystem guidance and a runnable Base portfolio example using illustrative data.
